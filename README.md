### Featured Projects

#### [antigravity-telegram-bridge](https://github.com/patrickpatrick27/antigravity-telegram-bridge)
Autonomous 24/7 mobile interface and daemon bridge for Google Antigravity (AGY) and Claude Code running on Linux hosts.
- **Stack:** Python, systemd, Telegram Bot API, async subprocess execution
- Features persistent session state, automated stream buffering, and robust background process orchestration.

#### [Kaong-Monitor](https://github.com/patrickpatrick27/Kaong-Monitor)
Specialized IoT telemetry monitoring dashboard for automated fermentation and agricultural systems.
- **Stack:** Flutter, Firebase Realtime Database, ESP32, GitHub Releases OTA
- Real-time telemetry visualization, temperature/Brix cycle tracking, and zero-downtime Over-The-Air firmware updates.

#### [NAP-Finder](https://github.com/patrickpatrick27/NAP-Finder)
High-performance offline-first GIS application for field technicians to locate and navigate Network Access Points in low-connectivity areas.
- **Stack:** Flutter, OpenStreetMap Tile Caching, Serverless Sheets Sync
- Zero-maintenance distributed database, local map tile storage, and instant offline geospatial queries.

#### [Pay-Tracker](https://github.com/patrickpatrick27/Pay-Tracker)
Privacy-first payroll assistant and earnings tracker with strict 30-minute rounding rules and automatic break deductions.
- **Stack:** Flutter, Google Drive REST API, Secure Local Storage
- Seamless multi-device sync without third-party server lock-in.
